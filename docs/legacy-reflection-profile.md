# 無属性武器の反射・跳ね返し v5

`legacy-weapon-reactions-subset-v5` は、無属性武器への反射・跳ね返しを追加した限定profile。
CLIと `gr_*` は既存の中立・奇跡・4属性・確率攻撃も有効にし、合計130種で動く。
現行公式の完全再現ではない。

## 対象と出典

[旧版の反応処理の調査](legacy-reflection-rules.md)と
[台帳・出典](../data/legacy-reflection-v1/README.md)を参照。

| 旧ID | 通常の攻撃 | 防御時の反応 | 旧重み |
| --- | --- | --- | --- |
| 20 | 無属性ATK5 | 無属性武器を跳ね返す | 6 |
| 39 | 無属性ATK10 | 無属性武器を反射する | 3 |

通常の攻撃に使う場合は、それぞれATK5/10の武器として扱う。攻撃しただけでは反射しない。
武器なので捨てられない。通常の防御値を持つ神器と、特殊な反応の役割を混同しない。
追加プールの重み9を含む全機能構成の重み合計は302。
制限プール内で旧重みを正規化し、公式の配布分布とは扱わない。

今回は通常の無属性武器攻撃だけを返せる。
属性付き攻撃、確率武器（今回の台帳では全て有属性）、回復や所持金増加、奇跡には使えない。
REFLECT_ANY、属性消去、防御奇跡、無効化、特殊効果付き反射等は対象外。
元の効果を狭めて別の単純な神器として台帳へ加えることはしない。

## 反射・跳ね返しと手番

- 反射: 現在の攻撃元と対象を入れ替え、新しい対象に防御を選ばせる。
- 跳ね返し: 反応した人物を新しい攻撃元とし、生存者から対象を抽選する。1対1でも本人を含む。
- 跳ね返しが本人へ向かうと、再防御を選ばせず、元の攻撃力で即座に解決する。
- 他方へ向かえば再び防御応答を待つ。反射をさらに反射することも可能。
- 通常手番の所有者は連鎖中に変えず、命中判定もし直さない。
- 手札の消費に応じて両者の配布予定が蓄積する。連鎖が終わるまで補充しない。
- 解決後に生存者へ座席順で配布し、既存の通常手番順へ戻る。元の攻撃者が倒れた場合も固定座席で勝敗・報酬を決める。

連鎖専用のゲーム上の回数制限は導入しない。
各反応で手札を消費し、途中に補充がないため、今回の手札容量から有限に収まる。
学習用の意思決定上限は別に適用し、反応待ちの状態で打ち切る場合も保存・復元できる。

## 通常防具を先に使う行動

旧版では、通常防具の後で反射に達すると、返す攻撃は元の攻撃オブジェクトから再構成される。
そのため、先行防具は消費されるが、反射する攻撃力の軽減には残らない。

例: ATK10に対して「DEF30 → 反射」を使うと、DEF30と反射武器を消費し、ATK10を返す。
最初の特殊反応で処理を抜けるので、その後の選択品は未消費となる。
この未消費の末尾を意味的な行動から省き、最初の特殊反応までを表現する。

既存のActionKindと6byteのC構造は変えず、`defend` のbaseを拡張した。

| 行動 | base | slots | target |
| --- | --- | --- | --- |
| 通常防御 | 255 | 通常防具のmask。空も可能 | 255 |
| 反応 | 特殊反応の手札位置 | その前に使う通常防具のmask。空も可能 | 255 |

baseをslotsへ重複させたり、slotsへ別の特殊反応を混ぜたりはできない。
このsubsetの通常防具は順序非依存なので、前置部分をmask、最後の特殊だけをbaseで表せる。
通常防具の全てを先に消費し、次に特殊を消費する。
将来、前置防具に順序依存効果を追加する際は同じ表現で足りると仮定しない。

## 状態・復元

`Pending::source/target` は現在の攻撃元と対象、`State::turn_owner` は元の通常手番の所有者。
反射後はsourceとturn_ownerが異なり、turn_owner本人が次の防御を選ぶこともある。
両側の配布予定を持てるよう復元時の検証を更新した。

`reaction_count` は未解決の現在の連鎖の反応回数。連鎖の解決時に0へ戻す。
`last_reaction` は最後の公開反応記録で、神器ID・反応者・実際の対象・種類を持ち、解決後も保持する。
`StepResult::reflected/bounced/bounce_self` は、そのstepで実行した反応だけを返す。
統計では持続する最後の記録を毎step再計上しない。

Snapshotは反撃拡張と共通のversion36。現在の連鎖、両者の配布予定、現在source/target、通常手番順、
公開記録、ゲーム乱数と検証用prefixを保存する。
反応の回数と消費予算、sourceの交代、最後の反応との整合も検証する。
反応を持たないprofileへの手札や連鎖状態の持ち込みは拒否する。

保持奇跡からの反射や万能反射は未対応なので、今回の連鎖は手札を消費する武器から始まる。
各座席の `hand_count + pending_deals <= 16` という予算検証はこの範囲で有効。
保持奇跡を満杯のまま使って返す場合の予定配布17等へ、現在の検証を一般化しない。

`script_bounce_targets()` で固定座席0/1の最大64件の対象prefixを指定できる。
不正入力は原子的に拒否し、使い切ったらseed付き抽選へ戻る。
指定部分はゲーム乱数を進めない。未来の値やprefix位置は観測へ出さない。

## C++・ABI・観測

```cpp
godfield::legacy::Env env({512, 10, true, true, true, true});
env.reset(42);
```

`Config::reflection` のデフォルトはfalseで、他の機能flagとは独立。
v5の識別名は共通なので、再現のためにはConfigの全flagも保存する。
CLIと `gr_create` はv5までの機能を有効にし、病気・harmsは無効の構成を生成する。

C++の共通観測は反撃拡張後の1345次元で、`gr_*` ABI 5は先頭236次元を返す。
この反応profileでは末尾1109個は0。[病気profile](legacy-disease-profile.md)と[harms profile](legacy-harms-profile.md)も参照。
構成要素maskは7種類。
従来6種の末尾へ反応スロットmaskを追加した。maskだけでなく `legal()` も検証する。
既存 `gl_*` / `gm_*` / `ge_*` / `gc_*` は128 / 164 / 186 / 210次元を維持する。

| 位置 | 内容 |
| --- | --- |
| 0〜209 | [確率profile](legacy-chance-profile.md)の定義を維持 |
| 210〜225 | 自分の各手札位置の反応enum / 3。none=0、reflect=1、bounce=2。block=3は今回の台帳にはない |
| 226 | 反応有効profileなら1 |
| 227 | 現在の連鎖の反応数 / 32 |
| 228 | 保留効果があり、現在の攻撃元が通常手番所有者と同じなら1。反応無効profileでは0 |
| 229 | 最後の公開反応記録があれば1 |
| 230 | 最後の反応神器ID / 363 |
| 231〜232 | 最後の反応が反射 / 跳ね返しならそれぞれ1 |
| 233〜234 | 最後の反応者 / 対象が現在の行動プレイヤーならそれぞれ1 |
| 235 | 最後の反応者と対象が同じなら1 |

反応無効profileでは追加26個は全て0。
相手の隠れた反応神器や未来の跳ね返し先は出さない。
[ReflectionBatchEnv](../python/reflection_env.py) は外部依存なしのctypesラッパー。
検証用の命中・跳ね返し対象prefixを指定できる。
バッチの原子的拒否、終了行の凍結、固定座席報酬、自動resetなしという契約を維持する。

## 実行

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j 4
ctest --test-dir build --output-on-failure
python3 python/reflection_env.py
./build/godfield_legacy_bench 100000 1 42 reflection
./build/godfield_legacy_bench 100000 4 42 reflection
```

reflectionのchecksumはversion5。既存4profileの計算式は維持する。
速度には行動生成・状態更新・統計処理を含み、モデル推論・観測転送は含まない。
旧版由来の限定環境として検証し、現行公式との動的照合はまだ行っていない。
万能反射、魔法反射、防御奇跡、属性消去、状態異常、守護神、蘇生、終末、複数人戦等は未対応。

### 今回の検証結果（2026-10-31）

通常ビルドのCTestは16件、ASan/UBSanビルドは11件が通過。
反射31回の在庫限界までの連鎖、先行防具・全16枚の消費、連鎖中の無配布、双方の配布順、
自己着弾、元の通常行動者が倒れる場合、打ち切り・復元・秘匿、1000seed再現を検証した。

全機能有効の10万試合・seed42・意思決定上限512で、1スレッドと4スレッドの次の値が一致した。

| 座席0 / 座席1の勝利数 | 50,212 / 49,788 |

| 反応総数 | 80,541 |
| 反射 / 跳ね返し | 26,709 / 53,832 |
